Part V: Write Unit Tests

What Are Unit Tests?

Unit tests verify that your code works correctly.

  • Catch bugs early before they affect your analysis
  • Document expectations about how code should behave
  • Enable safe changes - tests alert you if changes break things

We will write two tests:

  1. Test that our data file exists and has correct dimensions
  2. Test that a data cleaning function works correctly

Step 13: Set Up testthat

DO THIS: Initialize the testing infrastructure

RStudio Console:

usethis::use_testthat()

Terminal:

Rscript -e 'usethis::use_testthat()'

This creates:

  • tests/ folder
  • tests/testthat/ for test files
  • tests/testthat.R runner script

Checkpoint: tests/testthat/ folder exists

Step 14: Create Test File

DO THIS: Create a test file for data tests

RStudio Console:

usethis::use_test("data-validation")

Terminal:

Rscript -e 'usethis::use_test("data-validation")'

# Or create manually:
mkdir -p tests/testthat
touch tests/testthat/test-data-validation.R

This creates tests/testthat/test-data-validation.R for editing.

Step 15: Write Test 1 - Data File Validation

DO THIS: Edit test-data-validation.R with the following content

RStudio: Open and edit the file directly.

Terminal:

cat > tests/testthat/test-data-validation.R << 'EOF'
test_that("penguins data file exists and has correct dimensions", {
  data_path <- "analysis/data/raw_data/penguins.csv"

  expect_true(file.exists(data_path))

  penguins_data <- read.csv(data_path)

  expect_equal(nrow(penguins_data), 344)
  expect_equal(ncol(penguins_data), 8)
})
EOF
test_that("penguins data file exists and has correct dimensions", {
  data_path <- "analysis/data/raw_data/penguins.csv"

  expect_true(file.exists(data_path))

  penguins_data <- read.csv(data_path)

  expect_equal(nrow(penguins_data), 344)
  expect_equal(ncol(penguins_data), 8)
})

Save the file.

Step 16: Create Helper Function

DO THIS: Create a function to clean the penguins data

RStudio Console:

usethis::use_r("clean-data")

Terminal:

mkdir -p R
cat > R/clean-data.R << 'EOF'
#' Remove rows with missing values from penguins data
#'
#' @param data A data frame of penguin measurements
#' @return A data frame with complete cases only
clean_penguins <- function(data) {
  data[complete.cases(data), ]
}
EOF

This creates R/clean-data.R. Add the function code shown above.

Save the file.

Step 17: Write Test 2 - Function Validation

DO THIS: Create another test file

RStudio Console:

usethis::use_test("clean-data")

Terminal:

cat > tests/testthat/test-clean-data.R << 'EOF'
test_that("clean_penguins removes rows with missing values", {
  test_data <- data.frame(
    species = c("Adelie", "Gentoo", "Chinstrap"),
    bill_length = c(39.1, NA, 46.5),
    body_mass = c(3750, 4500, NA)
  )

  cleaned <- clean_penguins(test_data)

  expect_equal(nrow(cleaned), 1)
  expect_equal(cleaned$species, "Adelie")
  expect_false(any(is.na(cleaned)))
})
EOF

Add the test code to test-clean-data.R and save.

Troubleshooting Reference

“rrtools not found”

RStudio Console:

remotes::install_github("benmarwick/rrtools")

Terminal:

Rscript -e 'remotes::install_github("benmarwick/rrtools")'

“GitHub PAT not found”

RStudio Console:

usethis::create_github_token()
gitcreds::gitcreds_set()

Terminal:

Rscript -e 'usethis::create_github_token()'
# Then follow browser instructions
Rscript -e 'gitcreds::gitcreds_set()'
# Paste your token when prompted

“Test failed”

  • Check file paths are correct
  • Make sure you saved all files
  • Run devtools::load_all() before devtools::test()

“could not find function”

RStudio Console:

devtools::load_all()

Terminal:

Rscript -e 'devtools::load_all()'
