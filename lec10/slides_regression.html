Part I: The Palmer Penguins Dataset

Dataset Overview

The Palmer Penguins dataset (Gorman et al., 2014):

  • Collected at Palmer Station, Antarctica (2007-2009)
  • Three species: Adelie, Chinstrap, Gentoo
  • Morphometric measurements: bill length, bill depth, flipper length, body mass
  • 344 observations (333 complete cases)

Our goal: Predict body mass from morphometric measurements

Why Palmer Penguins?

Advantages over the iris dataset (Horst et al., 2022):

  • Realistic data: Missing values, unbalanced groups
  • Intuitive variables: Flipper length vs. sepal width
  • Documented provenance: Published research data
  • Ethical considerations: No association with eugenics research

Part III: Simple Linear Regression

Model Specification

Simple linear regression model:

\[\text{body\_mass}_i = \beta_0 + \beta_1 \cdot \text{flipper\_length}_i + \epsilon_i\]

where \(\epsilon_i \sim N(0, \sigma^2)\)

model_simple <- lm(body_mass_g ~ flipper_length_mm, data = penguins_clean)

Part V: Simpson’s Paradox

The Paradox Revealed

p1 <- ggplot(penguins_clean, aes(x = bill_depth_mm, y = body_mass_g)) +
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm", color = "black") +
  labs(title = "Overall: Negative", x = "Bill Depth (mm)", y = "Body Mass (g)")

p2 <- ggplot(penguins_clean, aes(x = bill_depth_mm, y = body_mass_g,
                                  color = species)) +
  geom_point(alpha = 0.7) +
  geom_smooth(method = "lm", se = TRUE) +
  scale_color_manual(values = species_colors) +
  labs(title = "Within Species: Positive", x = "Bill Depth (mm)",
       y = "Body Mass (g)")
p1 + p2

What’s Happening?

Simpson’s Paradox (Pearl, 2014):

  • Overall correlation: negative
  • Within-species correlation: positive

Why?

  • Gentoo penguins: large bodies, shallow bills
  • Adelie penguins: smaller bodies, deeper bills

Species acts as a confounding variable.

The Solution

Include species in the model to properly account for this confounding:

model_species <- lm(body_mass_g ~ bill_length_mm + bill_depth_mm +
                      flipper_length_mm + species, data = penguins_clean)

Part VIII: Cross-Validation

Why Cross-Validation?

  • Training R-squared can be overly optimistic
  • Cross-validation provides honest performance estimates
  • Essential for comparing models

10-Fold CV Setup

library(caret)
set.seed(42)
train_control <- trainControl(method = "cv", number = 10)

Cross-Validation Results

cv_simple <- train(body_mass_g ~ flipper_length_mm,
                   data = penguins_clean, method = "lm",
                   trControl = train_control)

cv_species <- train(body_mass_g ~ bill_length_mm + bill_depth_mm +
                      flipper_length_mm + species,
                    data = penguins_clean, method = "lm",
                    trControl = train_control)

CV Performance Comparison

tibble(
  Model = c("Simple", "Species-Aware"),
  CV_RMSE = c(cv_simple$results$RMSE, cv_species$results$RMSE),
  CV_R_squared = c(cv_simple$results$Rsquared, cv_species$results$Rsquared)
) |> mutate(across(where(is.numeric), ~round(.x, 3)))
# A tibble: 2 × 3

Part IX: Key Takeaways

Summary

  1. Flipper length is the strongest single predictor of body mass
  2. Simpson’s Paradox: Always check for confounding variables
  3. Species-aware models resolve the paradox and improve fit
  4. Model diagnostics confirm assumptions are reasonable
  5. Cross-validation provides honest performance estimates

Best Practices

  • Explore data visually before modeling
  • Check for confounding variables
  • Include relevant covariates
  • Validate with held-out data
  • Report honest performance metrics
